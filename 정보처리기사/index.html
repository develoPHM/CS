9-1. 소프트웨어 개발 보안 설계

보안의 3요소

용어설명
기밀성인가되지 않은 개인·시스템의 접근에 따른 정보 공개 및 노출을 차단
무결성정당한 방법이 아니면 데이터 변경 불가. 데이터의 정확성·완전성 보장
가용성권한을 가진 사용자나 애플리케이션이 원하는 서비스를 지속해서 사용할 수 있도록 보장

접근 통제 기법

용어설명
식별자신이 누구라고 신원을 밝히는 행위
인증주체의 신원을 검증하는 행동
인가인증된 주체에게 접근을 허용하는 활동
책임추적성주체의 접근을 추적하고 행동을 기록하는 활동

서버 접근 통제 유형

유형설명
DAC임의적 접근 통제사용자·그룹의 신분 기반으로 접근 제한. 권한을 가진 사용자가 자기 판단으로 다른 사용자에게 권한을 허용
MAC강제적 접근 통제시스템 정보의 허용 등급 기준으로 접근 제한. 관리자가 권한을 지정
RBAC역할 기반 접근 통제조직 내 맡은 역할 기반으로 접근 제한

대칭키 암호 방식

블록 암호
긴 평문을 고정 길이 블록 단위로 암호화 DES · 3DES · AES · IDEA · SEED · ARIA · Skipjack · RC5
스트림 암호
매우 긴 주기의 난수열을 발생시켜 평문과 결합해 암호문 생성 LFSR · RC4 · TKIP
알고리즘설명
DES1975년 미국 국립표준국(NBS, 현 NIST) 발표. 블록 64bit, 키 56bit
3DESDES 키 2개로 암호화-복호화-암호화(또는 복호화-암호화-복호화)를 세 번 수행
AESNIST 발표. DES·3DES의 문제를 해결하려고 개발한 블록 암호
SEEDKISA(한국인터넷진흥원) 개발
ARIA국정원과 산학연협회가 개발
IDEADES를 대체하려고 스위스 연방기술원에서 발표. PES → IPES → IDEA
RC5미국 Rivest가 개발. 블록 크기 32·64·128bit
Skipjack미국 NSA가 개발한 Clipper 칩 내장 블록 알고리즘. 전화기 등 음성 암호화에 주로 사용
LFSR선형 되먹임 시프트 레지스터. 선형 함수로 주로 XOR 사용. 초기 비트 값은 Seed

비대칭키(공개키) 암호 알고리즘

알고리즘설명
디피-헬만1976년 고안한 최초의 공개키 알고리즘. 이산대수 이용
RSAMIT 교수들이 고안. 소인수분해 이용
ElGamal이산대수 계산이 어려운 문제가 기본 원리
ECCRSA의 대안. 타원 곡선군의 이산대수 문제에 기초
DSANIST가 공포한 디지털 서명 표준

데이터 암호화 전송

프로토콜설명
IPSecIP 계층에서 VPN 암호화 연결을 설정하는 보안 프로토콜
  • AH: 무결성 보장. 인증 기능만 제공
  • ESP: IP 페이로드를 암호화해 기밀성 제공. 인증 + 암호화 기능 제공
SSL/TLS전송계층과 응용계층 사이에서 웹 데이터 암호화, 상호 인증, 무결성을 보장하는 보안 프로토콜
S-HTTP웹 트래픽을 암호화하는 방법. 모든 메시지를 암호화하며 HTTP 애플리케이션에만 적용 가능

VPN 관련 프로토콜

프로토콜설명
PPTPPPP 기술을 확장해 개발. 라우터·클라이언트에서 널리 쓰는 통신 규격
L2TPL2F와 PPTP를 결합한 규격. 하나의 터널에 여러 연결을 지원해 다자간 통신 가능
SSTP독점적인 SSL 기반 VPN 프로토콜
OpenVPN다양한 OS를 지원하는 오픈소스 VPN

보안 솔루션·도구

용어설명
Honeypot허니팟일부러 취약하게 만든 시스템으로 해커를 유인해 공격 방식 정보를 수집·추적
Tripwire크래커가 침입해 백도어를 설치하거나 설정 파일을 변경했을 때 이를 감지하는 분석 도구
SIEM머신러닝·빅데이터 기술로 IT 시스템의 대량 로그를 통합 관리·분석해 위협에 사전 대응하는 보안 솔루션
TrustZoneARM이 개발한 하드웨어 기반 보안 기술. 프로세서 안에 독립된 보안 구역을 두어 중요한 정보를 보호
난독화역공학에 대비해 코드의 가독성을 낮추도록 프로그램 코드를 변경
Digital Forensic사법기관 제출용으로 범죄 관련 디지털 증거를 수집·복사·분석·제출하는 일련의 과정
ping접속하려는 원격 호스트가 정상인지 진단하는 명령어
Tcpdump네트워크 인터페이스를 거치는 패킷 내용을 출력하는 프로그램
URL Rewrite클라이언트 요청 메시지 헤더의 URL을 관리자가 목적에 맞게 변경할 수 있도록 지원하는 기능
Tor토르 네트워크네트워크 경로를 알 수 없도록 암호화 기법을 사용해 익명으로 인터넷 사용

9-2. 소프트웨어 개발 보안 구현

입력 데이터 검증 및 표현 취약점

취약점설명
XSS크로스 사이트 스크립팅웹사이트에 악의적인 스크립트를 삽입해, 그 페이지를 열람한 사용자의 브라우저에서 스크립트가 실행되게 하여 정보를 탈취
CSRF사이트 간 요청 위조로그인된 사용자의 인증 정보(쿠키 등)를 이용해, 사용자 의지와 무관하게 공격자가 의도한 행위(수정·삭제·등록)를 서버에 요청하게 함
SQL InjectionSQL 삽입입력값 검증 취약점을 악용해 SQL 구문에 악의적인 쿼리를 삽입, DB 제어권을 얻고 데이터를 변조·유출

XSS vs CSRF XSS는 취약한 웹사이트를 이용해 클라이언트(사용자)를 공격하고, CSRF는 사용자의 권한을 도용해 서버를 공격한다.

메모리·실행 취약점

용어설명
Buffer Overflow버퍼 오버플로우할당된 버퍼 크기를 초과하는 데이터를 입력해 복귀 주소 등 프로세스 흐름을 바꾸고 악성 코드를 실행
  • 스택 버퍼 오버플로우: 지역 변수·Return Address가 저장되는 스택 영역에서 발생
  • 힙 버퍼 오버플로우: 동적으로 할당되는 힙 영역에서 발생
Race Condition레이스 컨디션둘 이상의 프로세스·스레드가 공유 자원에 동시에 접근할 때 순서·타이밍 차이로 생기는 비정상 결과(권한 획득 등)를 악용

버퍼 오버플로우 대응 방안

기법설명
Stack Guard스택가드복귀 주소(RET)와 지역 변수 사이에 카나리(Canary) 값을 넣고, 함수 종료 시 변조되었으면 프로그램 강제 종료
Stack Shield스택쉴드리턴 주소를 별도 안전 스택(Global RET)에 복사해 두고, 함수 종료 시 비교해 다르면 종료
ASLR주소 공간 배치 난수화실행할 때마다 스택·힙·라이브러리의 메모리 주소 배치를 랜덤화해 공격자가 주소를 예측하지 못하게 함

9-3. 보안 공격 기법

서비스 거부 공격 (DoS·DDoS)

용어설명
DoS서비스 거부 공격단일 공격 지점에서 과도한 트래픽을 발생시켜 서비스를 중단시킴
DDoS분산 서비스 거부 공격봇넷 등 여러 공격 지점에서 동시에 공격해 규모와 파괴력을 키움
Ping of Death죽음의 핑ICMP 패킷을 정상보다 아주 크게 만들어 전송 → 대량 단편화 → 재조합 과정에서 부하·오버플로우 발생
Ping Flooding대량의 ICMP Echo 요청으로 네트워크 자원을 고갈
SYN FloodingTCP 3-Way Handshake를 의도적으로 중단시켜 서버의 대기 큐를 모두 소모하게 만듦
UDP Flooding대량의 UDP 패킷을 임의의 포트로 보내 자원을 고갈
Smurfing스머핑출발지 주소를 공격 대상 IP로 위장해 ICMP Echo를 네트워크 전체에 브로드캐스트 → 응답이 대상에 집중
TearDrop티어 드롭IP 패킷의 Fragment Offset 값을 조작·중복시켜 재조립 시 과부하·오류 발생
LAND Attack랜드 어택송신 IP와 수신 IP를 모두 공격 대상 IP로 변조 → 대상이 자신에게 무한히 응답
봉크 (Bonk)같은 시퀀스 번호를 계속 보냄
보잉크 (Boink)일정한 간격으로 시퀀스 번호에 빈 공간을 만듦
RUDYR-U-Dead-Yet?HTTP POST 헤더의 Content-Length를 크게 설정한 뒤 바디를 1바이트씩 아주 천천히 보내 연결을 붙잡아 자원 고갈

스니핑·스푸핑 (네트워크 공격)

용어설명
Sniffing스니핑직접 공격하지 않고 네트워크에 흐르는 패킷을 몰래 엿보는 수동적 공격
네트워크 스캐너, 스니퍼공격자가 HW·SW 구성의 취약점을 파악하려고 탐색하는 도구
Spoofing스푸핑'속이다'라는 뜻. IP·MAC·DNS 등 식별 정보를 위장해 접근 통제를 우회하거나 데이터를 가로챔
IP Spoofing자기 패킷 헤더를 인증된 호스트의 IP 주소로 위조
ARP Spoofing특정 호스트의 MAC 주소를 자신의 MAC 주소로 위조한 ARP Reply를 지속적으로 보내 LAN 패킷을 가로챔
DNS SpoofingDNS를 조작해 정상 사이트 대신 가짜 사이트로 접속을 유도
ICMP Redirect3계층에서 스니핑 시스템을 또 다른 라우터라고 알려 패킷 흐름을 바꿈
Switch Jamming스위치 재밍위조 MAC 주소를 계속 흘려 스위치의 MAC 테이블을 채움 → 스위치가 더미 허브처럼 모든 패킷을 브로드캐스트
Session Hijacking세션 하이재킹로그인된 정상 세션을 가로채 인증 없이 사용자 권한으로 접근
Evil Twin이블 트윈합법적인 Wi-Fi처럼 위장한 가짜 핫스팟으로 접속한 사용자의 정보를 탈취
WindTalker윈드토커Wi-Fi·핫스팟에 연결된 디바이스의 무선 신호 패턴을 스니핑
Bluebug블루버그블루투스 장비의 취약점을 이용해 원격 제어·통화 도청·정보 탈취
IoT-SSDP프로토콜 취약점단순 서비스 검색 프로토콜(SSDP)의 특성을 이용해 IoT 기기를 좀비 PC로 이용

피싱·사회 공학

용어설명
Social Engineering사회 공학기술이 아닌 사람의 신뢰·심리적 약점을 이용해 권한이나 비밀 정보를 얻어냄
Phishing피싱'낚다(Fishing)'에서 유래. 신뢰할 수 있는 기관·지인으로 위장해 개인정보를 알아냄
Spear Phishing스피어 피싱특정 조직의 개인을 노려 일반 메일로 위장, 링크·첨부파일 클릭을 유도하는 표적형 피싱
Whaling웨일링고위 임원·관료 등 거물(Whale)을 노린 피싱
Smishing스미싱SMS + Phishing. 악성 링크 문자로 개인·신용 정보를 빼내고 소액결제 피해를 입힘
Qshing큐싱QR코드 + Phishing. QR코드로 악성 앱 설치를 유도해 금융 사기
Pharming파밍악성코드나 DNS 조작으로, 올바른 주소를 입력해도 가짜 사이트로 접속되게 함
Typosquatting타이포스쿼팅, URL 하이재킹주소 오타를 노려 유명 도메인과 비슷한 도메인을 미리 등록
Watering Hole워터링 홀목표 조직이 자주 방문하는 사이트를 미리 감염시켜 방문자를 감염
SCAM이메일 무역 사기기업 이메일을 해킹한 뒤 거래처로 위장해 '송금 계좌가 바뀌었다'는 메일로 거래 대금을 가로챔

계정·비밀번호 공격

용어설명
Cracking크래킹시스템 파괴나 정보 탈취를 목적으로 보안을 해제하는 행위
